# 🏦 Bank Management System (C++)

## 📌 Overview
This is a console-based Bank Management System developed in C++.  
It uses Object-Oriented Programming and file handling to manage customer accounts.

---

## 🚀 Features
- Create Account
- Deposit Money
- Withdraw Money
- Search by Name
- PIN Authentication
- Interest Calculation
- File-based data storage

---

## 🛠️ Technologies Used
- C++
- File Handling (Binary Files)
- OOP Concepts

---

## ▶️ How to Run
```bash
g++ bank.cpp -o bank.exe
.\bank.exe
